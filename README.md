## Overview
This repository contains the code for the **Car Price Prediction with Machine Learning** project completed as part of the CodeAlpha Data Science Internship. The goal is to build a regression model to estimate vehicle market prices based on attributes like brand, mileage, fuel type, and manufacturing year.

## Project Workflow
1. **Dataset Loading:** Automatically fetched the car price dataset using `kagglehub`.
2. **Data Preprocessing:** Handled missing values, cleaned column structures, and applied one-hot encoding to categorical features.
3. **Model Training:** Split the data into training and testing sets, then trained a **Random Forest Regressor**.
4. **Model Evaluation:** Evaluated performance using regression metrics including Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and $R^2$ Score.
5. **Visualization:** Plotted a scatter graph comparing actual prices against model predictions.
